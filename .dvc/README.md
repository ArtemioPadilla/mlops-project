# DVC Configuration

This directory contains DVC (Data Version Control) configuration files.

## Setup for New Users

1. **Copy the example config:**
   ```bash
   cp .dvc/config.example .dvc/config
   ```

2. **Edit `.dvc/config` and add your AWS credentials:**
   ```toml
   [core]
       remote = myremote
   ['remote "myremote"']
       url = s3://dvc-bucket-equipo-27
       access_key_id = YOUR_AWS_ACCESS_KEY_ID
       secret_access_key = YOUR_AWS_SECRET_ACCESS_KEY
   ```

3. **Verify DVC is configured correctly:**
   ```bash
   dvc remote list
   # Should show: myremote    s3://dvc-bucket-equipo-27
   ```

4. **Pull data from remote:**
   ```bash
   dvc pull
   ```

## Files

- **`config.example`** - Template configuration (versioned in git)
- **`config`** - Your local configuration with credentials (NOT versioned, gitignored)
- **`.gitignore`** - Auto-generated by DVC (versioned)

## Security Note

⚠️ **NEVER commit `.dvc/config` with real credentials to git!**

The `.dvc/config` file is gitignored to prevent accidental credential exposure.
Always use `config.example` as a template.

## Alternative: Use AWS Profiles

Instead of hardcoding credentials, you can use AWS profiles:

```toml
[core]
    remote = myremote
['remote "myremote"']
    url = s3://dvc-bucket-equipo-27
    profile = your-aws-profile
```

Or set environment variables:
```bash
export AWS_ACCESS_KEY_ID=your_key
export AWS_SECRET_ACCESS_KEY=your_secret
```
